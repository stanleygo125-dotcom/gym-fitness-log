# My GYM Fitness Log

A workout logger web app for gym users, with a personal trainer role, goal setting and body progress tracking. Built by a team of 5 for a Republic Polytechnic module (C237).

## Tech
Node.js, Express.js, EJS, MySQL

## My part
- User registration, login/logout and session authentication
- Workout add, view, edit and delete, linked to the logged-in user's ID so users only see their own records

## Teammates' parts
Trainer workout management, trainer-trainee body progress, body progress tracker, goals and personal bests.

## Run it
1. npm install
2. Copy .env.example to .env and fill in your own database details
3. node app.js
4. Open http://localhost:3000
